One prompt, one game: an AI agent built a tiny Breakout game from a single
sentence, then recorded itself playing it. The video in the linked X post
shows the prompt, the agent working, and the real game running — paddle on
mouse or arrow keys, a bouncing ball, five rows of colourful bricks, 3 lives,
a score, and a win screen when every brick is cleared.

## Run it

Open `game/index.html` in any browser — no build step, no network, no
dependencies. Click or press Space to launch the ball; move the paddle with
your mouse or the arrow keys. Add `?demo=1` to the URL and the game plays
itself (autopilot paddle) so you can watch it without touching anything.

## The video

`video.mp4` (not committed) is the clip posted on X: the prompt on screen,
the agent typing the game into existence, real gameplay captured from this
very `game/index.html` in headless Chromium, and make.fun's referral end
card. The post is linked from `POST.json`.
